# NAZAR — Things We Admire

> A quiet, editorial gallery of images we happened to love.

A frontend-only image gallery built with **HTML, CSS, and vanilla JavaScript** — no backend, no build tools.

##  Features

- Irregular masonry-style grid with varied tile sizes
- Scroll-reveal animations and subtle floating accents
- Full-screen lightbox on click
- Editorial typography (Newsreader, Inter, IBM Plex Mono)

##  Tech Stack

HTML · CSS · Vanilla JS · Google Fonts · Unsplash images

##  Structure

```
nazar/
├── index.html
├── style.css
└── script.js
```

##  Run It

Open `index.html` in a browser. That's it.
